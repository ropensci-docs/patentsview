# patentsview: An R Client to the 'PatentsView' API

Provides functions to simplify the 'PatentsView' API
(<https://search.patentsview.org/docs/docs/Search%20API/SearchAPIReference/#api-query-language>)
query language, send GET and POST requests to the API's twenty seven
endpoints, and parse the data that comes back.
